## 📖 Description

**FashionApp** is a desktop application built with **Java Swing** that showcases fashion items, collections, and trends. This project demonstrates proficiency in:

- **GUI Development** with Java Swing
- **Object-Oriented Programming** principles
- **Event-Driven Architecture**
- **Data Management** and visualization

---

## ✨ Features

- 🎨 **Fashion Catalog** - Browse through fashion items
- 🖼️ **Image Display** - View clothing and accessory images
- 📋 **Item Details** - View detailed information about each item
- 🔍 **Search Functionality** - Find specific fashion items
- 📊 **Collection Management** - Organize items by category
- 🖱️ **User-Friendly Interface** - Intuitive navigation

## 🚀 Installation

### Prerequisites
- Java JDK 8 or higher
- Git

### Steps

```bash
# Clone the repository
git clone https://github.com/mastersflash19/fashionapp.git

# Navigate to project directory
cd fashionapp

# Compile the code
javac src/*.java

# Run the application
java src/Main
